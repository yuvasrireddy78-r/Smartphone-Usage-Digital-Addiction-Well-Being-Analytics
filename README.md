Smartphone Addiction Analytics Dashboard

Project Overview: This project analyzes smartphone usage data to identify patterns and factors associated with smartphone addiction. the project analyzes demographic, and lifestyle attributes such as 
screen time, social media usage, gaming hours, notifications, app opens, sleep, stress, and academic/work impact.

Objectives:
Analyze smartphone usage behaviour.
Identify high-risk user segments.
Study the relationship between screen time, sleep, stress, gaming and social media.
Create an interactive Power BI dashboard.

Dataset:
Dataset: Smartphone_Usage.csv
Records: 7,500
Columns: 16
Age: 18–35 years

Tools Used:
Python
Pandas
Power BI
Power Query
SQL
Git & GitHub

Project Workflow:
Data Collection → Data Cleaning → SQL Analysis → Power BI Preparation → Visualization → Dashboard → Reports → Insights

Dashboard
The dashboard includes:
KPI cards
Addiction analysis
Screen-time analysis
Age & gender comparison
Stress and sleep analysis
Social media and gaming analysis
Key Influencers

Key Insights:The analysis identifies important relationships between smartphone usage, screen time, social media, sleep, stress and addiction levels.

Conclusion:
The project provides an interactive dashboard for understanding smartphone addiction patterns and supporting data-driven digital well-being analysis.By combining data preprocessing, analysis, Power BI visualizations, KPIs, and reports, the project helps identify important behavioural patterns and high-risk user segments.
